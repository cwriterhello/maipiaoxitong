# 项目骨架结构介绍

+ **damai-captcha-manage-framework**   验证码组件模块
    - **damai-base-captcha** 验证码基础组件
    - **damai-captcha-framework**   验证码封装组件
+ **damai-common**   公共基础包
+ **damai-elasticsearch-framework**   elasticsearch封装组件
+ **damai-id-generator-framework**   分布式id生成器
+ **damai-redis-tool-framework**   redis相关组件
    - **damai-redis-common-framework** redis公共配置模块
    - **damai-redis-framework** redis操作封装组件
    - **damai-redis-stream-framework** redisStream操作封装组件
+ **damai-redisson-framework**   redisson封装组件 
    - **damai-redisson-service-framework**   redisson服务相关组件 
        * **damai-bloom-filter-framework**   布隆过滤器组件
        * **damai-redisson-common-framework**   公共包
        * **damai-repeat-execute-limit-framework**   防重复幂等组件
        * **damai-service-lock-framework**   分布式锁组件
    - **damai-service-delay-queue-framework**   延迟队列组件
+ **damai-server**   业务服务 
    - **damai-admin-service**   admin服务监控
    - **damai-base-data-service**   基础数据服务
    - **damai-customize-service**   定制化服务
    - **damai-gateway-service**   Gateway网关服务
    - **damai-mybatis-plus-service**   Mybatisplus生成器
    - **damai-order-service**   订单服务
    - **damai-pay-service**   支付服务
    - **damai-program-service**   节目服务
    - **damai-single-service**   单体服务
    - **damai-user-service**   用户服务
+ **damai-server-client**   业务服务的Feign调用 
    - **damai-base-data-client**  基础数据服务的Feign调用
    - **damai-customize-client**   定制化服务的Feign调用
    - **damai-order-client**   订单服务的Feign调用
    - **damai-pay-client**   支付服务的Feign调用
    - **damai-program-client**   节目服务的Feign调用
    - **damai-user-client**   用户服务的Feign调用
+ **damai-spring-cloud-framework**   微服务相关封装组件 
    - **damai-service-common**  服务公共包
    - **damai-service-component**  微服务公共包
    - **damai-service-gray-transition-framework**   灰度功能组件
    - **damai-service-hystrix**   Hystrix熔断插件
    - **damai-service-initialize**   服务初始化行为管理组件
+ **damai-thread-pool-framework**   线程池封装组件
+ **logs  ** 日志存放目录
+ **sql  ** 导入的数据库表和数据
